# House-rent-analysis-si-project


SI Lab project (B.Tech CSE AIDS, Semester V, Ramdeobaba University).

- **Dataset:** House Rent Prediction Dataset (Kaggle), 4,746 listings in 6 Indian cities.
- **Notebook:** House_Rent_SI_Project_with_Classification.ipynb (statistics, classification, regression, Gradio dashboard).
- **Model:** best_rent_model.pkl (best classifier, Logistic Regression).

## How to run
Open the notebook in Google Colab and select Runtime → Run all.
